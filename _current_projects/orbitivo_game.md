I am developing a board game with long time friend, Aidan Rodts. The game will focus on player-versus-player encounters to create a dynamic environment. We began developing this game about four years ago, and it has always fallen to the back burner, but we aim to have a playable prototype before the end of August 2026. The main turn cycle of this game focuses on having players place the board themselves using tiles with arrangements of straight lines, corners, T-intersections, and X-intersections. The turn will start with placing a board piece or trap card, rolling a die (or two, would have to run the math on it), moving your character, and then replacing whichever option you took at the beginning of your turn. The players are racing to retrieve a piece of treasure across the board and return it to the start. The board will have a defined maximum area, so while the paths players create are purely up to them, there is a predetermined border to promote player interference.
